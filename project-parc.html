Project Overview

GESTION-PARC1 is a web application developed during my internship at the Société Nationale des Chemins de Fer Tunisiens (SNCFT).

The application was designed to facilitate the management and monitoring of the vehicle fleet, missions and fuel consumption through a centralized web interface.

The system uses a relational MySQL database and a PHP backend connected to an HTML, CSS and JavaScript frontend.

Main Features

🚗 Vehicle Management

Add, edit, delete and display vehicles with their main information and category.

📋 Mission Management

Create and manage missions including dates, vehicle, driver, itinerary and status.

⛽ Fuel Management

Track fuel consumption associated with vehicles and missions.

📊 Reports & Statistics

Generate reports and statistics to monitor vehicle activity, missions and fuel consumption.

👤 User Management

Manage users and roles through dedicated interfaces and authentication features.

🗄️ Database Management

Store and organize application data using a relational MySQL database.

Database Structure

The application relies on a relational database designed to connect the main entities of the system.

Vehicles

Vehicle identification, brand, model, purchase year and category.

Missions

Mission dates, vehicle, driver, itinerary and status.

Fuel Consumption

Vehicle, mission, fuel type, quantity, date and comments.

Users

User information, authentication and roles.

My Work
